## Описание проекта

Данный проект посвящен решению фундаментальной задачи ядерной физики и радиационного мониторинга - автоматическому разделению смешанного потока частиц (**гамма-квантов** и **нейтронов**). Идентификация типов частиц выполнена методом анализа формы импульсов (Pulse Shape Discrimination, PSD) сцинтилляционного детектора на базе фотоэлектронного умножителя (ФЭУ).

Задача реализована в рамках парадигмы обучения без учителя (Unsupervised Learning) на реальном физическом датасете, содержащем **23 479 зарегистрированных событий**. Итоговое решение протестировано в соревновании на платформе Kaggle и достигло прецизионной точности **Accuracy = 0.84675**, полностью подтвердив теоретические основы физики сцинтилляционных детекторов.

## Архитектура и этапы решения

Пайплайн обработки данных структурирован в виде 7 последовательных этапов:

### 1. Исследовательский анализ данных (EDA)
* Исходная числовая матрица содержит 23 479 строк и 504 столбца.
* Первые 4 колонки идентифицированы как статические метаданные ФЭУ (температура, ID канала) и исключены из анализа как неинформативные.
* Столбцы с 4 по 504 представляют собой временные отсчеты осциллограмм сигналов. Технический шум в конце файла успешно отсечен сведением матрицы сигналов строго к 500 временным тактам.

### 2. Предобработка данных и калибровка
* **Цифровая фильтрация:** Для подавления высокочастотных аппаратурных помех электроники применен низкочастотный **фильтр Баттерворта 2-го порядка**. Использование двукратной фильтрации (`filtfilt`) позволило сгладить треки сигналов без внесения фазовых сдвигов.
* **Калибровка АЦП:** Сырые сигналы инвертированы и центрированы по физической формуле $2^{14} - сигнал - baseline$, учитывающей 14-битную разрядность АЦП детектора. Уровень тишины (`baseline`) рассчитан динамически для каждого импульса по его первым 40 тактам, что полностью нивелировало аппаратурный джиттер.

### 3. Feature Engineering (Проектирование признаков)
Для устранения «проклятия размерности» 500 сырых временных точек каждого импульса свернуты в 4 компактных физико-статистических признака формы:
* `volumes` - интегральная площадь импульса (выделенная энергия).
* `amplitudes` - пиковое значение амплитуды сигнала.
* `ratio` / `angles` - параметры, определяющие геометрическую крутизну наклона ветви.
* `kurt_values` - статистический эксцесс затухания, оценивающий вклад быстрой и медленной компонент высвечивания кристалла.
* `root_volumes` - нелинейное масштабирование энергии через квадратный корень для улучшения разделения в области малых энергий.

### 4. Подбор признаков и масштабирование
Для обучения моделей сформировано пространство из параметров `root_volumes`, `angles`, `ratio` и `kurt_values`. Для выравнивания масштабов применен алгоритм `RobustScaler`. Использование медиан и квантилей защитило модель от искажений, вызываемых эффектом насыщения ФЭУ на сверхвысоких энергиях.

### 5. Обучение и сравнительный анализ моделей
В ходе исследования были протестированы три альтернативные архитектуры с варьированием геометрических гиперпараметров ковариации:
1. **K-Means:** Ошибочно разделил выборку вертикальным срезом по мощности сигналов, проигнорировав форму хвостов.
2. **GMM Full:** Избыточная гибкость независимых эллипсов привела к переобучению в зашумленной области низких энергий.
3. **GMM Tied (Финальный выбор):** Жесткое ограничение параллельности эллипсов одинаковой формы идеально совпало с физикой расхождения треков частиц под фиксированным углом, обеспечив максимальную точность.

### 6. Визуализация и предсказание
Построенный физический график распределения амплитуд и площадей подтверждает эталонное разделение ветвей. Верхняя крутая ветвь (Класс 0) соответствует гамма-квантам, нижняя пологая (Класс 1) — нейтронам. Перемешивание цветов или наложение точек полностью отсутствует. Итоговый файл ответов экспортирован в формате CSV со строгим соблюдением PEP8.
